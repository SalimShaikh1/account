# OpenAI Prompt – Implement Multi-Device Session Management in an Existing Node.js + MongoDB + Angular Application

I already have a working application with separate Node.js (backend) and Angular (frontend) projects. The project structure, authentication flow, APIs, database models, and Angular architecture are already implemented.

**Do not generate a new project or change the existing architecture unless absolutely necessary.**

## Objective

Implement a secure multi-device login and session management mechanism.

## Existing Environment

## Functional Requirements

### Detect Existing Login

When a user logs in from another device:

* Detect whether the user already has one or more active sessions.
* Identify the currently active device(s).
* Do not allow duplicate session creation without user confirmation.

### User Decision

Return an API response that allows the Angular application to display a confirmation dialog.

The dialog should present options similar to:

* Continue login on this device and terminate the previous session(s).
* Cancel login and continue using the existing device.
* Keep both devices logged in (only if multiple concurrent sessions are enabled through configuration).

The backend should not assume a default choice.

The frontend must explicitly send the user's selected option.

## Force Logout Using WebSocket

Use WebSocket (or the existing socket implementation if already available) to perform real-time session management.

If the user chooses to continue on the new device while terminating the previous session:

* Immediately notify the previous device through WebSocket.
* Force logout the previous device without waiting for token expiry.
* Clear authentication state.
* Redirect the user to the login screen.
* Display a meaningful message explaining why the logout occurred.

If multiple concurrent sessions are allowed, no logout event should be sent.
